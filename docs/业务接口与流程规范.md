# 智能代码判题与教学辅助系统 (CourseJudge) - 业务接口与流程规范

## 1. 核心业务流程流转

### 1.1 系统启动与编译器自适应探针流程

```mermaid
sequenceDiagram
    autonumber
    actor User as 用户 (教师/学生)
    participant Launcher as run.py (启动入口)
    participant Probe as 编译器智能双模探针
    participant Server as FastAPI 内嵌服务
    participant Window as PyWebView 原生窗口

    User->>Launcher: 双击启动 run.py 或 CourseJudge.exe
    Launcher->>Probe: 1. 探针自适应检测 C++ 编译器
    alt 系统已配置 MinGW/g++
        Probe-->>Launcher: 命中模式 1: 系统原生 g++
    else 系统未配置
        Probe-->>Launcher: 命中模式 2: 项目内置便携绿色 g++ (~50MB)
    end
    Launcher->>Server: 2. 异步启动本地 FastAPI 业务服务
    Launcher->>Window: 3. 唤起 PyWebView 独立桌面客户端窗口 (加载应用界面)
    Window-->>User: 呈现桌面软件登录与主界面 (右下角显示: 编译器已就绪)
```

---

### 1.2 老师：班级管理 $\to$ 智能出题编排 $\to$ 发布作业

```mermaid
sequenceDiagram
    autonumber
    actor Teacher as 老师
    participant Front as 教师端桌面界面
    participant API as 后端 API
    participant LLM as LLM API
    participant Judge as 探针命中的 g++ 编译器
    participant DB as SQLite 数据库

    Teacher->>Front: 1. 创建班级 (系统生成 6 位随机邀请码)
    Front->>API: POST /api/v1/classes
    API->>DB: 写入班级信息

    Teacher->>Front: 2. 点击“布置作业”，填写作业标题、截止时间、模式(练习/考试)
    Teacher->>Front: 3. 在作业中点击“AI 辅助出题”
    Front->>API: POST /api/v1/llm/generate-problem (输入意图/知识点)
    API->>LLM: 调用大模型生成题面与标准 C++ 解答
    LLM-->>API: 返回题面 + AC 代码
    API-->>Front: 界面展示预览题面与代码

    Teacher->>Front: 4. 点击“自动生成测试用例”
    Front->>API: POST /api/v1/llm/generate-testcases
    API->>LLM: 分析边界生成测试输入数据
    LLM-->>API: 返回测试输入
    API->>Judge: 编译标准 C++ 解答，喂入测试输入，捕获输出作为期望结果
    Judge-->>API: 返回 100% 准确的标准输出
    API-->>Front: 返回完整题目及测试用例

    Teacher->>Front: 5. 确认无误，点击“加入作业清单”
    Teacher->>Front: 6. 确认整份作业题目列表，点击“发布作业至班级”
    Front->>API: POST /api/v1/assignments (关联班级与全部题目)
    API->>DB: 持久化作业与题目数据
    API-->>Front: 发布成功
```

### 1.3 学生：作业做题 $\to$ 考后短板一键诊断 $\to$ 专属强化训练题本

```mermaid
flowchart TD
    A[学生输入班级邀请码加入班级] --> B[在'我的作业'列表中查看对应班级的作业]
    B --> C{作业模式选择}
    
    C -->|练习模式| D1[编写 C++ 代码]
    D1 --> D2[可先'自测运行'查看自定义输入输出]
    D2 --> D3[点击'提交判题': 即时查看全部用例通过情况并允许重复修改]
    
    C -->|考试模式| E1[编写 C++ 代码]
    E1 --> E2[可多次'自测运行'检查基本逻辑]
    E2 --> E3[确认完成点击'正式交卷': 仅此一次机会, 锁定答题]

    D3 --> F[作业/考试结束]
    E3 --> F
    F --> G[点击 'AI 短板诊断']
    G --> H[系统调用 LLM 综合分析未满分题目与代码逻辑缺陷]
    H --> I[生成诊断报告: 指出具体薄弱知识点, 如'动态规划-状态转移']
    I --> J[点击 '针对该弱点生成专项强化题']
    J --> K[AI 生成 1 道阶梯巩固题与用例, 自动存入'强化训练题本']
    K --> L[学生在'强化训练'模块中随时复盘, 重复练习]
```

## 2. 核心 RESTful API 规范

### 2.1 系统健康与探针状态 (`/api/v1/system`)

| 请求方法 | 路径 | 功能描述 | 返回数据示例 |
| :--- | :--- | :--- | :--- |
| `GET` | `/status` | 获取系统健康与编译器探针状态 | `{"compiler_mode": "builtin", "compiler_path": "...", "db_connected": true, "version": "1.0.0"}` |

---

### 2.2 班级管理模块 (`/api/v1/classes`)

| 请求方法 | 路径 | 权限 | 功能描述 | 核心参数说明 |
| :--- | :--- | :--- | :--- | :--- |
| `POST` | `/` | 教师 | 创建新班级 | `name`: 班级名称；系统自动生成 6 位 `invite_code` |
| `GET` | `/my` | 教师/学生 | 获取当前用户所属的班级列表 | 教师返回自己创建的班级，学生返回已加入的班级 |
| `POST` | `/join` | 学生 | 通过 6 位邀请码加入班级 | `invite_code`: 班级邀请码 |
| `GET` | `/{id}/students` | 教师 | 查看班级内所有已加入学生 | Path: `id` |

---

### 2.3 作业与题目管理模块 (`/api/v1/assignments`)

| 请求方法 | 路径 | 权限 | 功能描述 | 核心参数说明 |
| :--- | :--- | :--- | :--- | :--- |
| `POST` | `/` | 教师 | 发布作业/考试 | `class_id`, `title`, `type` (`practice`/`exam`), `start_time`, `end_time`, `problems` 数组 |
| `GET` | `/class/{class_id}` | 学生/教师 | 获取某班级下的全部作业列表 | 区分待开始、进行中、已截止 |
| `GET` | `/{id}` | 学生/教师 | 获取作业详情与题目清单 | 考试未开始前只展示倒计时 |
| `GET` | `/{id}/dashboard` | 教师 | **班级学情与薄弱知识点大屏** | 返回：应交人数、实交人数、平均分、各分数段人数直方图、各题正答率漏斗、薄弱知识点 Top 诊断 |

---

### 2.4 判题与自测模块 (`/api/v1/judge`)

#### 1. 自测运行 (仅编译运行，不判分)
- **请求方式**：`POST /api/v1/judge/run-test`
- **请求体 (Body)**：
  ```json
  {
    "code": "#include <iostream> ...",
    "custom_input": "5\n1 2 3 4 5"
  }
  ```
- **响应体 (Data)**：
  ```json
  {
    "status": "Success",     // Success / Compilation Error / Runtime Error / Time Limit Exceeded
    "output": "15",
    "error_message": "",
    "execution_time_ms": 15
  }
  ```

#### 2. 正式提交判题 (练习/考试提交)
- **请求方式**：`POST /api/v1/judge/submit`
- **请求体 (Body)**：
  ```json
  {
    "assignment_id": 1,
    "problem_id": 10,
    "code": "#include <iostream> ...",
    "is_final_exam_submit": false   // 考试交卷时置为 true
  }
  ```
- **响应体 (Data)**：
  - **练习模式**：返回详细分数、用例通过详情、最大耗时、失败样例类型。
  - **考试模式**：提交成功后返回交卷凭据，界面输入框锁定。

---

### 2.5 学生专属强化训练题本 (`/api/v1/training`)

| 请求方法 | 路径 | 权限 | 功能描述 | 核心参数说明 |
| :--- | :--- | :--- | :--- | :--- |
| `GET` | `/my` | 学生 | 获取个人历史强化训练题列表 | 展示知识点标签、题目名称、历史最佳评测状态 (`AC`/`WA`) |
| `GET` | `/{id}` | 学生 | 查看单道强化题详情 | Path: `id` (题面、输入输出样例) |
| `POST` | `/{id}/submit` | 学生 | 针对专属强化题进行提交判题 | `code`: C++ 源码，返回实时测评结果与得分 |

---

### 2.6 大模型 (LLM API) 核心接口 (`/api/v1/llm`)

#### 1. 教师：智能出题
- **请求方式**：`POST /api/v1/llm/generate-problem`
- **入参**：`{"prompt": "出1道二叉树后序遍历的中等题", "knowledge_tag": "二叉树"}`
- **返回**：标题、题面 Markdown、输入输出样例、标准 C++ 解答代码。

#### 2. 教师：自动生成测试用例
- **请求方式**：`POST /api/v1/llm/generate-testcases`
- **入参**：`{"problem_description": "...", "standard_code": "..."}`
- **机制**：LLM 生成边界输入，后端自动调用编译器运行标准解答并抓取输出，返回 100% 正确配对用例集。

#### 3. 学生：考后一键短板分析
- **请求方式**：`POST /api/v1/llm/diagnose-assignment`
- **入参**：`{"assignment_id": 1}`
- **返回**：`weak_point` 标签、代码逻辑缺陷诊断、解题思路指导。

#### 4. 学生：针对短板生成专属强化训练题
- **请求方式**：`POST /api/v1/llm/generate-training-problem`
- **入参**：`{"assignment_id": 1, "weak_point": "动态规划-状态转移方程"}`
- **返回**：生成 1 道结构化巩固题目及测试用例，并在数据库中自动落库至该学生的专属训练题本。

#### 5. 首页 AI 助手问答 (支持流式 SSE)
- **请求方式**：`POST /api/v1/llm/chat`
- **入参**：`{"message": "请解释一下什么是拓扑排序，它的应用场景有哪些？"}`
- **返回**：流式或标准 Markdown 解答内容。
