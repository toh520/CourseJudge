# 团队一键启动脚本维护技能 (Maintain Startup Scripts Skill)

> **技能使命**：  
> 本课设项目采用**团队多人协作开发模式**。任何团队成员通过 `git pull` 拉取最新代码后，必须能够在无须手动配置繁琐步骤的情况下，**双击一键脚本直接自动完成依赖同步、配置初始化并顺利启动客户端**。  
> AI Agent 在进行任何可能影响环境的开发工作时，必须调用本技能规范进行同步维护。

---

## 1. 触发时机 (Trigger Scenarios)

当你在开发过程中执行以下任何操作时，**必须同时维护一键启动脚本与环境配置**：
1. **新增、升级或删除 Python 第三方库**（修改了代码中的 `import`）；
2. **新增或修改了系统环境变量**（如新增了配置项字段）；
3. **调整了服务启动入口或主程序参数**（如重命名 `run.py` 或改变了启动参数）；
4. **新增了运行时必须的本地文件存储路径**（如新增了特定文件夹）；
5. **重构了项目文件组织结构**。

---

## 2. 团队环境一致性四步检查清单 (Checklist)

AI Agent 在完成相关代码编写后，必须对照以下四步自检：

### 步骤 1：同步更新 `project/requirements.txt`
- 确保新增依赖已记录入 `requirements.txt`，并标注**合理的兼容版本区间**（如 `fastapi>=0.110.0,<1.0.0`）；
- 必须附带**标准中文用途注释**；
- 严禁引入需要本地 C++ 编译环境构建的复杂包，优先选择全平台有现成 Wheel 的纯 Python 或预编译库。

### 步骤 2：同步更新 `project/.env.example`
- 若业务新增了配置项（如新增了某个开关参数），**必须在 `.env.example` 中补充占位符和中文使用说明**；
- 严禁在 `.env.example` 中泄露任何真实的个人 API Key 或私密连接。

### 步骤 3：验证与维护 `project/start.bat`
- 检查 `start.bat` 内部的执行逻辑是否覆盖以下 5 大环节：
  1. **Python 环境探针**：检查用户电脑是否具备 Python 3.10+，若无给出友好的中文安装指引；
  2. **虚拟环境自动化**：若不存在 `.venv`，全自动调用 `python -m venv .venv` 创建，免去团队成员手动输入命令；
  3. **依赖自动对齐**：使用国内高速镜像（如清华源 `https://pypi.tuna.tsinghua.edu.cn/simple`）静默同步 `requirements.txt`；
  4. **配置自动兜底**：检查 `.env`，若首次运行不存在，自动从 `.env.example` 复制一份并输出提示，防止因为缺少配置文件而报错闪退；
  5. **运行目录确保**：自动创建必要的本地工作路径（如 `storage/temp_judge/` 等）；
  6. **唤起应用**：调用 `.venv\Scripts\python run.py` 并提供异常日志暂停查看。

### 步骤 4：确保根目录 `一键启动.bat` 的跳转可靠
- 根目录下的 `一键启动.bat` 必须使用安全相对路径：
  ```bat
  @echo off
  chcp 65001 >nul
  cd /d "%~dp0project"
  call start.bat
  ```
- 确保任何小白团队成员在根目录双击该文件时，均能顺畅拉起 `project/start.bat`。

---

## 3. 常见团队协作“翻车”防范守则

1. **防路径锁定**：严禁在启动脚本中写入任何固定绝对路径（如 `D:\code\...`），必须严格使用相对路径 `%~dp0`；
2. **编码防乱码**：Windows 批处理脚本必须声明 `chcp 65001 >nul`，并在保存文件时统一使用 **UTF-8 无 BOM 编码**，防止中文提示在 Windows 命令提示符中出现乱码；
3. **网络加速**：安装依赖时必须指定国内镜像源参数 `-i https://pypi.tuna.tsinghua.edu.cn/simple`，杜绝团队成员因校园网或外网超时导致安装失败。
